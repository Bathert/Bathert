<summary><b>🤖 Hermes damage report</b></summary>

<br />

В какой-то момент хотел просто автоматизировать рутину. Теперь у меня локальная агентная среда, профили под проекты, память, cron-задачи и привычка сначала потратить 16 часов на автоматизацию, а потом 8 часов проверить, почему руками было бы быстрее.

| Режим | Симптом |
|---|---|
| Product mode | Сначала выясняю, что на самом деле нужно пользователю |
| Engineering mode | Потом превращаю это в работающий код и проверки |
| Agent mode | Затем делегирую рутину и проверяю, что агент не придумал результат |

</details>
